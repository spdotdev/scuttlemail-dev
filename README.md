# scuttlemail-dev

The scuttlemail.dev site, packaged as a Laravel library for a host app (sd-admin).

```
composer install
./vendor/bin/pint --test
./vendor/bin/phpstan analyse
./vendor/bin/phpunit
```

See `CLAUDE.md` for layout and deploy steps, and `docs/DNS-AND-MAIL-SETUP.md` for the
mailbox and DNS plan.
